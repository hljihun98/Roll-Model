# 모델 적용 범위와 변경 사항

이 프로그램은 설계 스크리닝 도구입니다. 계산이 완료됐다는 `ok: true`와 종합 판정 `worst: 'ok'`는 다릅니다. 전자는 입력으로 수치를 계산했다는 뜻이며, 종합 판정은 하중·모델 적용성·응력·온도 검사를 모두 포함합니다.

## 하중과 입력 검증

- 휠 반력이 음수이거나 한 줄 지지점으로 편심 모멘트를 받을 수 없으면 종합 불가입니다. 지지점을 다시 결정하는 비선형 접촉해석은 구현하지 않았습니다.
- 안전율은 1 이상, 듀티는 0~1, 포아송비는 0 이상 0.5 미만이어야 합니다. 숫자의 유한성·자료형, 재질과 탭 열거값, 정수 휠 수, 반지름·폭과 트레드·라운드의 기하 관계를 검사합니다.
- 입력 한계와 판정 기준은 다릅니다. 잘못된 입력은 수치 결과를 지우고 계산을 거부합니다. 적용 범위를 벗어난 모델은 참고 수치와 불가 사유를 함께 표시합니다.
- 자동 충격계수는 표시 상한으로 잘리더라도, 원래 추정이 상한을 넘으면 종합 불가입니다.

### 4바퀴 배치와 3점 접지

기본값과 승용차·선회 시나리오는 전후 2열 × 좌우 2행입니다. SUV의 8휠 시나리오와 이전 설정 파일에 저장한 배치는 유지합니다. 이전 파일에 접지 조건이 없으면 전체 접지를 적용합니다.

전체 접지는 기존 등강성 지지 모델을 사용합니다. 3점 접지는 2×2의 네 모서리 중 사용자가 지정한 비접지점의 반력을 0으로 두고, 나머지 3점의 수직 반력을 정정 평형식 `Σr_i = 1`, `Σr_i x_i = eₓ`, `Σr_i y_i = e_y`로 풉니다. 여기서 `r_i = R_i/(Wg)`, 등가편심은 기하편심에 `(a/g) h_cg`를 더한 값입니다. 계산 근거는 [Engineering Statics §5.5, 3D rigid-body equilibrium](https://engineeringstatics.org/Chapter_05-3d-rigid-body-equilibrium.html)입니다.

반력 합과 두 축 모멘트를 보존하며 좌표를 축거·윤거로 정규화해 크기 차이의 영향을 줄입니다. 반력이 음수인 해를 0으로 잘라 유효한 해로 바꾸지 않습니다. 분담률 수치 허용오차 `1e-10` 이내의 0은 경계로 처리하고, 그보다 작은 음수는 지지 불가로 판정합니다. 중심 하중에서는 두 대각 바퀴가 각각 50%, 나머지가 0%인 경계 해이므로 단순 `Wg/3`과 다릅니다.

3점 정정 모델에는 전체 접지용 평탄도 재분배 계수 `k3`를 중복 적용하지 않습니다. 주행 하중은 `Wg max(r_i)`이며, 단차 충격과 후속 응력·열 검사는 기존 계산 체인으로 이어집니다. 사용자가 지정한 비접지 상태의 정적 평형만 검사하며, 바닥 높이·프레임 변형에 따라 비접지점을 자동으로 선택하는 모델은 아닙니다.

지지 불가를 치수·질량·속도·듀티 변경으로 해결할 수 없는 경우 개선 제안의 반복 탐색을 생략합니다. 비접지점 4곳의 독립 평형 검증, 동적 등가편심 대조, 경계·전도 판정, 잘못된 입력, 이전 파일 호환성과 실제 UI 저장/불러오기를 회귀 테스트로 검사합니다.

## 도막과 기재

기존 `exp(-1.2·t/b)` 강성 혼입식은 출처를 확인할 수 없어 삭제했습니다. 새로운 옵션은 **균질 반무한체 두 개를 비교**합니다. 도막과 기재의 환산강성 `E/(1−ν²)` 중 큰 값을 선택해 접촉해를 계산합니다. 두 균질체 가정 중에서는 높은 면압을 고르지만, 실제 층상 탄성체의 면압 상한을 수학적으로 보장하지는 않습니다.

두께에 따른 임의의 강성 보간은 하지 않습니다. 두께는 기재 전달압·트레드 구속·도막 분류에 사용합니다. 도막이 있는 조건은 모델 적용성에서 최소 주의로 분류하며, 층상 탄성해 또는 실측 확인을 요구합니다. 옵션을 끄면 도막 물성만 사용하므로 그 한계 역시 주의로 표시합니다.

## 크라운과 타원접촉

종방향 상대곡률은 `1/Rx = 1/(D/2) + 1/R2`, 횡방향은 `Ry = crown`입니다. 근사식에 넣을 때 곡률반경 비가 1 이상이 되도록 축을 정렬하고, 계산 후 종방향 반폭 `b`와 횡방향 반폭 `a`로 복원합니다. 면압은 `3F/(2πab)`이며 화면에도 같은 식을 표시합니다. 곡률비 1에서 구 접촉 해와 비교하는 회귀 검증을 유지합니다.

**후속 응력장·마찰·기재 전달압·구름저항·열은 선접촉용 모델입니다.** 현재 타원 수치 전체를 3D 설계 결과로 승인할 수 없어 모델 적용성 게이트를 불가로 표시합니다. 접촉 타원이 휠 폭을 넘으면 표시하는 선접촉 값 역시 참고값이며, 불가 판정을 유지합니다. 이는 오류를 숨겨 통과시키지 않기 위한 명시적인 지원 범위입니다.

근사식 문헌: [NASA TM-81691, 접촉 타원 매개변수](https://ntrs.nasa.gov/citations/19810023007). 코드에 사용된 계수의 직접 문헌 대응과 전체 곡률비 범위에 대한 독립 수치해 검증은 후속 연구 과제입니다. 기존 출처 표기의 연도만으로 전체 응력장까지 검증됐다고 해석하면 안 됩니다.

## 허용치와 열

- 콘크리트 지압은 `0.85 f_ck √(A₂/A₁) / SF`입니다. 근거 없는 고정 배수 1.445 대신 지지 면적비를 입력하며 기본값은 1, 상한은 4입니다. 이는 프로그램의 스크리닝 비교값이며 설계코드 전체 요구사항을 구현한 인증 계산서는 아닙니다.
- 온도는 속도와 무관하게 재료 허용온도와 비교합니다. 허용온도를 넘으면 불가입니다. 섭씨 온도를 비율로 나눈 경고 구간은 제거했습니다.
- 주변온도가 허용온도를 넘으면 열 기준 허용하중은 0입니다. 주변온도가 허용온도와 같고 발열이 있으면 역시 0입니다. 발열이 없고 주변온도가 허용범위 이내면 열 모델이 별도 하중 제한을 주지 않아 무한대로 표시합니다.
- 캘리브레이션은 온도 여유와 발열이 양수일 때만 가능합니다. 계산된 절대 보정계수를 적용하므로 버튼을 반복해서 눌러도 누적되지 않습니다.
- 단부 완화 계수, 충격 상한, 경고 구간, 무도장 표면 부착 비 등 정책값은 상세 입력에서 조절하며 실측 검증 대상임을 표시합니다.

## 구현하지 않은 현상

반복 피로, 정차 크리프, 3D 타원접촉의 마찰 응력장, 부분 슬립 해, 베어링 수명, 프레임 동적 응답, 바닥 거칠기는 별도 해석이 필요합니다. 코드 회귀 검증 통과는 이러한 물리 현상까지 실험적으로 검증됐다는 뜻이 아닙니다.
